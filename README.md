# Auto Fill Fields

A JavaScript project that automatically fills form fields — useful for testing and form automation workflows.

## Features
- Auto-populates input fields on page load
- Configurable field mappings
- Works with standard HTML forms

## Tech Stack
- Vanilla JavaScript
- HTML5 Forms API

## Usage
Include the script in your HTML and configure field mappings in `config.js`.
